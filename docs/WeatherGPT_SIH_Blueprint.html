1. End-to-End System Architecture

WeatherGPT is engineered to resolve the critical rural last-mile gap in meteorological decision support. Rather than providing generic forecasts, it grounds advanced conversational models (Google Gemini 2.5 Flash) directly into high-resolution live sensor telemetry, NWP numerical predictions, and Doppler radar sweeps.

2. Website (PWA) Technical Workflow & Hierarchy

The web platform is an enterprise-grade, Single-Page Application (SPA) designed with a mobile-first AMOLED glassmorphic aesthetic. It operates completely without heavy front-end frameworks (Zero React/Vue overhead), loading instantly with raw Vanilla ES Modules and native DOM manipulation.

• sheet-nwp: Ensemble Consensus (GFS, ECMWF, ICON, WRF) & Model Spread • sheet-aviation: Synthetic ICAO METAR, Runway Crosswind component & VFR/IFR • sheet-climate: Decadal Trends (1991-2025), Thermal Anomaly & CSV Export • sheet-travel: Origin-to-Destination Highway Hazard & Rain Analysis • sheet-telemetry: 7-Day Precision Forecast & Hourly Matrix Timeline

2.1 Web Platform Component Breakdown

1. Dynamic Ambient Aura & Living Orb

CSS conic gradients dynamically synchronize with current atmospheric conditions: Cyan (#06b6d4) for clear skies, Amber/Orange for severe heatwaves, and Violet/Red during thunderstorm convective advisories.

2. Persona Quick-Action Cards

Provides 1-tap pre-grounded actions: Agri Spray (checks humidity < 80% and wind < 15 km/h), Rain & Commute, Highway Safety, and Severe Disaster Warning.

3. Speech Synthesis & Multi-Indic Voice

Web Speech API integration allows rural and illiterate users to listen to AI responses synthesized aloud in Hindi, Telugu, Marathi, Tamil, Kannada, and English.

4. Live Doppler GIS Map Layer

Leaflet.js map layer synchronized with RainViewer API (/api/weather/radar). Allows full interactive playback of the past 2 hours of radar sweep reflectivity with time scrubbing.

A major vulnerability in generic AI assistants is hallucination and off-topic deviation. WeatherGPT implements Strict Topic Boundary Guardrails both at the prompt injection layer for Google Gemini 2.5 Flash and in the local deterministic heuristic fallback engine.

5. Multi-Tier Persistence & Scientific Formulas

5.1 3-Tier Storage & Resilience Matrix

Storage Tier Component Stored Data & Indexes Failover / Offline Behavior
Tier 1: In-Memory L1 Redis (ioredis) 15-minute weather cache keys (weather:lat:lon). Ensures sub-5ms response times. Transparent bypass. If Redis is unavailable or unconfigured, queries proceed to L2/L3 with zero interruption.
Tier 2: Cloud L2 MongoDB Atlas (cluster0.yxmk02g) • weather_cache: GeoJSON 2dsphere spatial index & TTL expiration
• climate_history: 30-day recorded telemetry & anomalies
• ai_conversations: Audit prompts, answers, personas, coordinates
• favorite_places: Pinned locations 		If MongoDB Atlas is unreachable, connection times out in 4s, and system automatically falls back to local SQLite without throwing 500 errors.
Tier 3: Embedded L3 SQLite (weathergpt.sqlite) Local file-based database storing user preferences, persistent AI keys, local cache, and search history. Always active on the local file system. Operates with 100% offline autonomy.

5.2 Scientific Meteorological Formulas Implemented

1. Runway Crosswind Component

Implemented in aviationService.js:

Crosswind = WindSpeed × |sin(θwind - θrunway)|
Headwind = WindSpeed × |cos(θwind - θrunway)|

Provides critical landing clearance in knots for pilots and agricultural drone sprayers.

2. Composite Disaster Risk Index (0–100)

Implemented in weatherService.js:

Risk = 0.35×RainScore + 0.30×WindScore + 0.20×HeatIndex + 0.15×AQIScore

Maps continuously to IMD 4-stage color alerts: Green (<30), Yellow (30-55), Orange (55-80), Red (>80).

3. ICAR Foliar Spray Window Algorithm

Implemented in climateService.js:

Optimal = (Wind < 15 km/h) && (RainProb < 40%) && (Humidity ∈ [50%, 80%])

Prevents pesticide runoff into rural groundwater and maximizes chemical absorption efficiency.

4. Monsoon LPA Deviation (%)

Implemented in climateService.js:

Anomaly% = ((ObservedRain - LPA_Normal) / LPA_Normal) × 100

Evaluates 30-day cumulative precipitation vs 30-year Long Period Average for drought early warning.
